# Demo / video pitch script (2–3 minutes)

Use this for the AKINDO demo video requirement.

1. **Hook (15s)** — Classic casinos either scam or dox. Midnight Casino proves fair play while keeping bet intent private.
2. **Problem (20s)** — Show README problem story briefly.
3. **Compact contract (45s)** — Open `midnight-contract/casino.compact`. Point to `placeBet` / `settleWheel`, witnesses, `disclose()`. Run `npm run compact` → “Compiling 4 circuits”.
4. **QA (20s)** — Run `npm test` in `midnight-contract` → 9 passing.
5. **UX (60s)** — `npm run dev` → `/game/privacy-wheel`. Place private bet, show public commitment JSON, settle win/loss. Call out what never left the client.
6. **Wave progress (20s)** — Show `WAVE1_PROGRESS.md`. Mention Wave 2 Lace/Preprod plan.
7. **Close (10s)** — Repo + Figma deck links; ask for feedback.

Recording tip: name the Midnight Buildathon Wave 1 in the first 10 seconds.
